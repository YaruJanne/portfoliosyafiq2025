GameSony Mocopi

Duel Beats

A PC rhythm boxing game built to show what the Sony Mocopi motion-capture kit can do. Upload any .wav song and the game analyses it and builds the beat map automatically, in real time.

ROLELead Developer
PLATFORMPC, Sony Mocopi
TOOLSUnreal Engine 5.4, MetaSound, LiveLink, Adobe Audition
RECOGNITIONSony Mocopi

Challenge 1: Latency

Vision-based tracking like Radical had a 200–300 ms delay, which breaks the precise timing a rhythm game needs. Moving to Sony Mocopi’s inertial sensors cut the delay to about 50 ms.

That brought a new problem, sensor drift. I added a quick-recalibration feature that keeps the player’s avatar aligned during long sessions.

Challenge 2: Beat accuracy

The first beat-detection algorithm picked up false beats in electronic tracks with a lot of background noise. I built a frequency-gating system in MetaSound with low-pass filters that isolate kick drums and bass, so gameplay targets sync to the song’s real rhythm.

Key numbers

~50 msmotion-to-screen latency
6-pointbody tracking via LiveLink
Any .wavsong can be uploaded and played
